# 메뉴 표출 통일

요청: 기존 로고·일러스트·네이비·연녹색 톤을 유지하면서 홈 중복과 메뉴별 표출 차이를 정리.

- 입력: main 847649e, 공개 아카이브, 홈 및 주요 메뉴 8개 실화면.
- 적용: codex-delivery-loop, 기존 KRDS 타이포그래피. website-minimal-interview는 기존 기획 범위 참조. 새 사업 기획·개인 Brain 승격·수집 기준 변경은 제외.
- 수락 기준: 홈 두 목록에 같은 URL/제목 재노출 없음, 공통 제목/검색/목록 형식, 필터 초기화와 빈 결과, 모바일 가로 넘침 없음, 공식 계획 탭과 지역 지도 보존.

## 반영

1. 상단 최근 동향 5묶음에 포함된 모든 URL·정규화 제목을 하단 목록에서 제외. 제목이 다른 동일 사건까지 추정하여 합치지는 않음.
2. ~~최근 기사~~ → **더 살펴볼 소식**. 배너와 옆 목록에 반복되던 전체 동향 링크는 배너 하나로 유지.
3. 모바일 ~~상단 전체 메뉴 + 하단 전체~~ → **하단 전체**.
4. 8개 메뉴 공통 intro·검색 영역·목록 타이포그래피 적용. 뉴스·칼럼·연구·중앙정부는 공통 검색/지역/주제/기간 컨트롤, 지자체·참여기구는 기존 전용 조건을 같은 접기형 패널에 배치.
5. 뉴스의 큰 날짜 달력은 시작일/종료일 입력으로 통일. 시간대 필터 유지. 홈 월간 달력 유지.
6. 정부조사·통계에도 자료명/기관 검색과 초기화 추가. 공식 계획 탭·지역 계획 지도·정적 통계 출처 카드는 고유 기능을 유지.
7. 기사 카드는 출처·날짜, 제목, 요약, 태그, 원문/공유/복사 순서와 크기를 통일.

## 검증

- Python 회귀 테스트 74개 통과(웹 생성 69 + 동향 5). 홈 URL/동일제목/다른출처 중복 제외 회귀 추가.
- 공개 아카이브 재생성 성공(상세 3030페이지).
- 로컬 브라우저 390px: 홈과 주요 메뉴 8개 모두 H1 1개, 가로 넘침 없음. 공통 검색창 확인.
- 뉴스 검색 결과 0건·초기화, 주거 주제 필터, 02시 시간대 필터(194건, 모든 결과 02:00)·전체 복구(2417건) 확인.
- 참여기구와 통계 검색 결과 0건 확인, 중앙정부 계획 탭 전환 확인.
- 분류·데이터 정확도나 44개 기획 전체 완료를 의미하지 않음.

배포와 최종 화면 증거는 PR 및 배포 기록으로 확인.
