# 청년 투게더 디자인 하네스 적용 기록

## 요청

- 작업: 최신 디자인 하네스의 6:3:1, 색상 선정, 타이포그래피, UX 라이팅 원칙을 공개 사이트에 다시 적용하고 GitHub에 반영한다.
- 유형: 구현 + 발행
- 날짜: 2026-07-31

## 프로젝트 계약

- 주제: 청년정책·청년이슈 정보 서비스
- 독자: 청년정책을 빠르게 탐색하는 개인과 실무자
- 목적: 정보의 출처와 우선순위를 빠르게 이해하고 다음 화면으로 이동하게 한다.
- 매체: 반응형 공개 웹사이트
- 완료 기준: 생성 원본 수정, 전체 페이지 재생성, 디자인·접근성·회귀 검사, GitHub 반영
- 핵심 가설: 넓은 저자극 배경, 신뢰 구조색, 희소한 행동색을 분리하면 정보 통제감과 행동 우선순위가 선명해진다.

## 색상 결정

| 배분 | 색상 | 역할 |
| --- | --- | --- |
| 60 | `#F8F6F0`, `#FFFDF8` | 페이지 배경과 읽기 표면 |
| 30 | `#102C32`, `#18464B`, `#DCEFEB` | 내비게이션, 정보 구조, 중립 태그 |
| 10 | `#C84D39` | 활성 메뉴, 핵심 행동, 긴급 신호 |

목표는 정책 정보 탐색 중의 피로를 낮추고 출처와 행동의 우선순위를 분명하게 하는 것이다. 청록과 코럴의 정서 효과는 보편 법칙으로 단정하지 않는다. 대비, 클릭, 이탈, 사용자 반응으로 검증할 설계 가설로 취급한다.

## 구현 판단

- 겹친 흰 카드와 그림자를 줄이고 아이보리 배경을 실제 60% 표면으로 사용한다.
- 청록은 좌측 내비게이션과 첫 화면의 정보 구조에 집중한다.
- 코럴은 활성 메뉴와 핵심 행동에만 사용하고 일반 태그는 민트·청록으로 돌린다.
- 첫 화면 브랜드명과 본문 대비를 높이고, 장식 그라데이션을 제거한다.
- 생성된 HTML이 아니라 `public-site/scripts/web_updater.py`를 정본으로 수정한다.

## 종료 관문

- 인벤토리 드리프트: `dashboard/harness_index.json`이 JSON 파싱 오류 상태다. 실제 하네스 파일을 정본으로 사용했고 자동 수정하지 않았다.
- 공개/비공개 경계: 내부 하네스 원문은 배포하지 않고 적용 기록만 공개 문서로 남긴다.
- 완료 판정: 생성·테스트·시각 검수·GitHub 반영 후 결정한다.
