# 동향 파악 중심 개선 — 2026-10-04

## 목적과 범위

공무원·청년센터·참여기구의 공통 첫 과업은 **동향 파악**이다. 최근 소식 → 관심 의제·지역 검색 → 출처와 원문 확인을 첫 흐름으로 둔다. 회의용 비교표와 정책제안 페이퍼는 후속 과업이다.

이번 변경은 화면 생성기와 최근 자료 선별·묶음 모듈이다. 개인정보, 구독, 유료 기능, 메시지 발송, 외부 API 호출은 추가하지 않는다. 기존 수집 파이프라인·자료실·달력은 재사용한다.

## 구현 계약과 실제 문구

- 입력: 기존 공개 기사 JSON, 마지막 수집 시각. 최근 여부는 빌드 실행 시각 기준 7일이며 오래된 마지막 성공 시각을 ‘현재’로 사용하지 않는다.
- 홈: ~~청년정책 AI 브리핑 보러가기~~ → **최근 7일, 청년정책 소식 / 전체 동향 살펴보기**.
- 기사 영역: ~~오늘의 기사~~ → **최근 기사**.
- 동향: 의제 선택, 지역·키워드 검색, 결과 수, 30개씩 더 보기, 원문 펼치기.
- 원문: 출처, 발행일, 공식 출처로 분류/언론·공개 자료를 표시한다. 공식 출처 분류는 공식 원문 대조 완료를 의미하지 않는다.
- 시행 상태: 검토 상태 reviewed/approved, 정책 단계, HTTP(S) 검토 근거 링크가 함께 있을 때만 단계 표시. 그 외는 **시행 상태 미확인**.
- 빈 결과: **조건에 맞는 자료가 없습니다. 필터를 초기화하거나 다른 키워드를 입력하세요.**
- 오래된 수집: 마지막 수집 시각과 **최근 수집 상태 확인 필요** 표시. 이 판정은 빌드 시점 기준이며 정적 페이지의 다음 빌드 전 시간 경과는 자동 반영하지 않는다.
- 출력: 정적 HTML/CSS/JS. 자바스크립트 없이도 자료·원문 링크는 남는다.

## 데이터 경계와 다음 고도화

현재 묶음은 **같은 제목·지역**의 자료다. 다른 제목의 동일 사건, 중앙 발표와 지역 시행을 자동으로 연결했다고 주장하지 않는다. 명시 청년 표현이 없는 관련 정책을 놓칠 수 있고, 제목에 청년이 들어간 약한 자료가 남을 수 있다. 분류를 확정 사실로 표시하지 않는다.

다음 단계는 자료량 확대보다 검토 가능한 정책 사건 데이터다.

1. `event_id / 담당기관 / 지역 / 사업명 / 회차·기간`으로 서로 다른 지역·차수의 오병합을 막는다.
2. 이전 발표·이번 발표의 문장과 원문 위치를 연결하고 변경 대상을 사람·지원액·일정·조건으로 기록한다.
3. `발표 / 의견수렴 / 공고 / 시행 / 결과`를 근거 링크·검토자·검토 시각과 함께 저장한다.
4. 의제별 카드에 검토된 ‘이번 변화’ 한 문장과 다음 확인사항을 제공한다. 근거 부족은 비교 불가로 표시한다.
5. 세 독자군 각 1명 이상이 관심 동향을 찾고 원문을 확인하는 사용성 실험을 실시한다. 시간 절감과 이해도는 현재 검증되지 않았다.

## 수락 증거

- 최근 자료·중복·관련성·안전한 URL·HTML 이스케이프·검토 상태: 신규 5개 단위 테스트.
- 기존 홈 53개, 날짜 8개, 지역 자료실 4개 테스트 통과. 합계 70개.
- 전체 정적 생성기 실행 완료(외부 썸네일 요청을 테스트에서 비활성화), 상세 페이지 3014개 생성. 별도 수집·외부 발송은 실행하지 않음.
- 브라우저: 390px·1280px 홈/동향, ‘광양’ 검색 3개, 주거 필터, 원문 펼치기, 빈 결과, 초기화 복구 확인. 640px 폭의 확대 대응 검사에서 가로 넘침 없음. 실제 브라우저 200% 줌과 스크린리더 전체 경로는 별도 검증 필요.

- 디자인: 기존 산세리프·파란 행동색 유지, 흰 표면과 구분선 중심. 제목 700/본문 400, 상태 본문 16px, 날짜·출처 메타 14px, 조작 높이 44px. 추가 장식·새 브랜드 레퍼런스 도입 없음.

상태: 구현 및 위 범위 검증 완료, 배포 전 검토 가능. 공개 사이트 반영·실제 독자 효용·정책 사건 의미 검증은 완료로 처리하지 않는다.
