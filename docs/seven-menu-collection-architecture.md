# 7개 메뉴 수집·공개 구조 초안

기준일: 2026-07-31

## 공통 원칙

- 공개 범위는 최근 1년이다. 수집 저장소는 장기 보관하되 화면은 최근 1년을 기본으로 보여준다.
- GitHub Actions가 30분마다 신규 자료를 확인한다. 정적 사이트이므로 이를 실시간이 아닌 `30분 주기 근실시간`으로 표현한다.
- 한 자료는 발행 주체와 문서 형식을 기준으로 주 메뉴 하나에만 배치한다.
- 수집 성공과 공개 성공을 분리한다. 날짜 미확인, 출처 불명확, 파서 실패는 누락시키지 말고 운영 상태로 기록한다.
- 제목·URL·발행처·게시일·본문 지문을 함께 사용해 중복을 제거하고 공식 원문을 대표 자료로 우선한다.

## 수집 우선순위

1. 광역지자체 17곳의 보도자료와 기본·시행계획 파서를 안정화한다.
2. 중앙부처는 현재 활성 파서를 기준으로 수집 성공률을 측정한 뒤 19개 부처 전용 어댑터를 순차 추가한다.
3. 기초지자체 약 226곳은 전면 수집하지 않는다. 광역 데이터의 누락률과 유지비가 안정된 뒤 수요가 높은 지역부터 추가한다.
4. 논문 전문을 무단 복제하지 않는다. 서지정보·초록·원문 링크 중심으로 수집하고 이용 조건을 보존한다.

## 운영 품질 지표

- 소스별 최근 성공 시각, 연속 실패 횟수, 최근 7일 수집량
- 원문 URL 확보율, 게시일 확보율, 본문 확보율
- 중복 제거율, 메뉴 미분류율, 메뉴 간 중복 노출률
- 공식자료의 기관·지역 커버리지
- 수집 후 공개까지의 지연 시간
